# FUTURE_PE_01
# AI Website Copy Generator for Local Businesses

## Internship Details
This project was created as part of the Prompt Engineering Internship Program by Future Interns.

## Business Chosen
Brew Haven Cafe

## About the Project
This project demonstrates how AI and Prompt Engineering can be used to generate high-quality website copy for local businesses.

The goal was to create:
- Homepage copy
- Services page content
- CTA (Call-To-Action) sections
- Structured reusable prompts

## Problem Solved
Many local businesses struggle with:
- unclear website messaging
- weak value proposition
- poor CTA sections
- generic website content

This project solves these issues using AI-generated conversion-focused website copy.
